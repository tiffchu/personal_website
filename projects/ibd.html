Overview

Turning multi-source data into usable research tools

This project works on turning raw clinical, dietary, biomarker, and mycobiome data into reproducible data products: cleaned processed files, exploratory visualizations, Quarto-based statistical reports, and a Shiny dashboard for participant- and cohort-level exploration.

The goal is to provide a non-technical audience of clinicians and researchers with a user-friendly interface to explore and combine IBD data sources and gain insights into IBD.

Approach

A modular, rerunnable analysis pipeline

Started with a data cleaning and preprocessing pipeline in Python before converting to R, with renv for environment management, followed by exploratory data analysis and visualization. This project uses Quarto for the statistical reporting site, and Shiny for the interactive dashboard. The approach is modular and pipeline-driven -> raw domain files are cleaned separately, standardized through shared helpers, merged into analysis-ready tables, and then reused across both the reporting site and dashboard so the same processed data powers all downstream outputs. The Makefile organizes the project into steps like cleaning, stats rendering, and app launch, so the same pipeline can be rerun end to end from raw inputs, with github pages re-rendering the stats site automatically.
