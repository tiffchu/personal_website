Overview

Practical text analysis without a command line

This Streamlit application supports common text-preprocessing and analysis tasks, including tokenization, lemmatization, part-of-speech tagging, named entity recognition, sentiment analysis, and time-series analysis.

The interface makes it easier for non-technical users to clean text, explore it through EDA, run mood detection with a zero-shot BART model, and build BERTopic models from their own uploaded dataset.

Approach

A lightweight analysis workflow in the browser

The app was developed in Python with Streamlit for the interface. The underlying workflow uses tools including Facebook Prophet, spaCy, BERTopic, NLTK, and Hugging Face Transformers to perform each linguistic task and visualize results with minimal setup.

The project was completed as part of an internship with the UBC Data Science Institute.
