Overview

Text analysis for non-technical users

An interactive Natural Language Processing application built with Streamlit to support text preprocessing and analysis tasks such as tokenization, lemmatization, part-of-speech tagging, named entity recognition, sentiment analysis, and time-series analysis. Which later is used in mood detection (Zero-Shot with BART model from Hugging Face), BERTopic modelling, recommender systems (mentor-mentee matching), text cleaning and EDA of text data. Project was part of an internship with the UBC Data Science Institute.

Approach

A lightweight analysis workflow in the browser

Developed in Python using Streamlit for the user interface, the app leverages Facebook Prophet, SpaCy, BERTopic, nltk, transformers, etc. for linguistic tasks. The pipeline performs the above tasks efficiently and visualizes results directly in the browser with minimal setup. A text dataset must be uploaded to see results.
