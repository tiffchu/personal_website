Masters Capstone

Reproducible Framework for IBD Analysis

BC Children's Hospital Research Institute

  • R & Shiny
  • Quarto
  • Data pipelines

Overview

Masters capstone project in partnership with BC Children's Hospital Research Institute. This project works on turning raw clinical, dietary, biomarker, and mycobiome data into reproducible data products: cleaned processed files, exploratory visualizations, Quarto-based statistical reports, and a Shiny dashboard for participant- and cohort-level exploration. The goal is to provide a non-technical audience of clinicians and researchers with a user-friendly interface to explore and combine IBD data sources and gain insights into IBD.

Tech & Approach

Started with a data cleaning and preprocessing pipeline in Python before converting to R, with renv for environment management, followed by exploratory data analysis and visualization. This project uses Quarto for the statistical reporting site, and Shiny for the interactive dashboard. The approach is modular and pipeline-driven -> raw domain files are cleaned separately, standardized through shared helpers, merged into analysis-ready tables, and then reused across both the reporting site and dashboard so the same processed data powers all downstream outputs. The Makefile organizes the project into steps like cleaning, stats rendering, and app launch, so the same pipeline can be rerun end to end from raw inputs, with github pages re-rendering the stats site automatically.

Data Science Internship

NLP Tool & Analysis App

UBC Data Science Institute

  • Python
  • Streamlit
  • NLP

Overview

An interactive Natural Language Processing application built with Streamlit to support text preprocessing and analysis tasks such as tokenization, lemmatization, part-of-speech tagging, named entity recognition, sentiment analysis, and time-series analysis. The overall goal is to enable non-technical users to apply mood detection (Zero-Shot with BART model from Hugging Face), BERTopic modelling, and text cleaning and EDA of text data. Project was part of an internship with the UBC Data Science Institute.

Tech & Approach

Developed in Python using Streamlit for the user interface, the app leverages Facebook Prophet, SpaCy, BERTopic, nltk, transformers, etc. for linguistic tasks. The pipeline performs the above tasks efficiently and visualizes results directly in the browser with minimal setup. A text dataset must be uploaded to see results.

Independent Research

Topic Modelling of ICU Transcripts

UBC School of Nursing

  • Python
  • LDA
  • Qualitative health data

Overview

This independent project was done with supervision and data from the UBC School of Nursing, exploring computational methods to quantify and analyze qualitative health data as part of a term-long research investigation. This project analyzes transcripts from intensive care unit (ICU) survivors using natural language processing (NLP) techniques. The aim is to identify the challenges people experience after hospitalization that might contribute to an unplanned readmission. This project is particularly meaningful to me as I was a participant in this study, after my discharge from RGH.

Research project is part of a qualitative study led by Dr. Fuchsia Howard. Link to Photovoice study

Approach & Methods

The work included data cleaning/ conversion, statistical modeling using Latent Dirichlet Allocation, and visualization to derive insights. The research was conducted in Jupyter notebooks and supported by written analysis. Tech stack included Gensim, SpaCy, pyLDAvis, sklearn, etc. Evaluation of the topic model was done with coherence scores and perplexity metrics.

Machine Learning Capstone

Anomaly Detection in U.S. Senate Investments

Financial disclosure analysis

  • Python
  • Anomaly detection
  • Time series

Overview

This project investigates unusual or statistically significant patterns in financial transactions associated with members of the U.S. Senate, using anomaly detection techniques to highlight outliers that may warrant closer inspection.

Methodology

The core pipeline includes data extraction and cleaning from publicly available financial disclosures, feature engineering to quantify investor behavior and combine with S&P market data, and the application of unsupervised anomaly detection models hierarchical clustering and LSTM autoencoders to identify unusual activity. Results are visualized with interactive plots and documented in analysis notebooks.
